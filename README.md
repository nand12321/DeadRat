## DeadRat

DeadRat is a small game built in 3 days for the **Game Zanga Fukaha Jam**.  
Jam page: https://itch.io/jam/fukaha1

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/nand12321/DeadRat
cd DeadRat
```

### 2. Install LÖVE (Love2D)

**Windows:**  
Download the installer from the official website:  
https://love2d.org/

**Ubuntu / Linux:**  
Install via your package manager:

```bash
sudo apt install love
```

### 3. Run the game

You may need to restart your terminal after installation.

```bash
love .
```
